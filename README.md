# Seascape Demo

使用 Unity URP 制作的海景 WebGL 演示，包含动态水面、倒影和多种画面风格。

## 在线体验

**[点击打开海景 Demo](https://li1ssk.github.io/seascape-demo/)**

建议使用电脑上的 Chrome 或 Microsoft Edge 浏览器，等待资源加载完成后，点击游戏画面以接收键盘输入。

## 操作方式

- 按 **E** 循环切换风格：写实 → 像素 → 卡通 → 油画 → 水墨。
- 点击画面右下角的全屏按钮进入全屏。
- 如果更新后仍显示旧版本，按 **Ctrl + F5** 强制刷新网页。

## 关于仓库

本仓库存放 WebGL 构建产物，通过 GitHub Pages 发布，不包含完整的 Unity 工程源码。

推送到 `main` 分支后，GitHub Actions 会自动部署网站。
